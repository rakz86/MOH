Tabs

For switching between views of the same object — never as a substitute for navigation between pages. A tab change must not lose unsaved work.

Counts sit in the tab where they exist. A tab with a zero count stays visible and disabled rather than disappearing — a menu that changes shape between visits is harder to learn.
