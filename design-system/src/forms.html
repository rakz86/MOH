The five rules

The requisition form is the product. These rules are not stylistic preferences — each one prevents a specific, measurable failure in government service forms.

01

One column. Multi-column forms cause skipped fields, because the eye does not reliably find the second column.

02

Visible, persistent labels. A placeholder is not a label — it vanishes exactly when the user needs to check what they are answering.

03

Hints above the input. Guidance read before answering prevents an error; guidance below is discovered after failing.

04

Errors name the fix. Say what to do, not that something is wrong.

05

Mark optional, not required. Where most fields are mandatory, flagging the exceptions is quieter and clearer.

And

Never ask twice. If the ministry already holds a value — department, budget code, supplier licence — prefill it and let the user correct it.

Attachments

Specification sheets, tender waivers, CE and FDA certificates. State the accepted formats and the size limit before the user tries — not in an error afterwards.

Validation

Validate on blur, never on every keystroke — telling someone their email is invalid while they are still typing it is hostile. On submit, show a summary at the top of the form that links to each failing field, and move focus to it.
