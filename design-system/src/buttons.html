Intents

Four intents, and the choice is about hierarchy rather than taste. Exactly one primary per view — the single action that advances the task. Two competing primaries in a form footer is the most common way to make a user hesitate.

Primary

The one action that moves the task forward.

Secondary

Real alternatives, equally valid.

Ghost

Tertiary and inline actions, low emphasis.

Danger

Destructive or irreversible. Always confirmed by a dialog.

Sizes

Default is the density-aware 48px (40px compact). Large is reserved for a single standout action on a landing page; small for table rows and toolbars where a full-height control would crowd the row.

States

Every intent carries the same five states. Focus is a 3px ring with a 2px offset and a contrast halo, so it stays visible on both light and dark surfaces — tab through the row below to see it.

Disabled buttons do not explain themselves. Prefer an enabled button that, when pressed, says what is missing. If a control must be disabled, put the reason in text beside it — a greyed button with no explanation is a dead end for the user.

Direction

Switch the toolbar to RTL — عربي. Chevrons and arrows carry .icon--directional and mirror; the plus sign does not, because a plus has no direction. Getting this wrong is the most visible sign that RTL was retrofitted.

Writing the label

Do

Name the outcome. A user scanning only the buttons should be able to tell what each one does.

Do not

Generic labels force the user back into the surrounding copy to work out what will happen.
