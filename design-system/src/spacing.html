Two densities, one system

The scale never changes. What changes is control height and table rhythm — so the public request form and the internal review queue stay visibly part of the same family while serving very different jobs. Toggle Comfortable / Compact in the toolbar to see both; the panels below are pinned so you can compare.

Comfortable — public, default

Requesters and suppliers. 48px controls, 56px rows, 44px minimum tap target. Touch and low-confidence users.

Compact — internal workbench

Procurement officers triaging a queue. 40px controls, 40px rows. Desktop and pointer only — never serve this to the public.

Compact is desktop-only. It drops below the 44px target floor, so it may never be used on a touch device or on any screen a member of the public reaches. The density attribute lives on a layout wrapper, never on an individual component.

Radius & elevation

Deliberately restrained. A ministry service should read as considered rather than playful — nothing is rounder than 12px except pills. Shadows are tinted with the brand blue rather than pure black, so raised surfaces stay in the same colour world as everything else.

Motion

Short and functional. Motion confirms that a state changed; it never decorates and it never delays. Anything over 240ms is making the user wait to watch an animation finish.

fast · 120ms
Hover, focus, colour shifts
normal · 180ms
Expanding panels, tab changes
slow · 240ms
Dialogs and drawers entering

Reduced motion is honoured at the token layer. Under prefers-reduced-motion: reduce every duration collapses to 1ms, so no component needs its own media query and none can forget to include one.
