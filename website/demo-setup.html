A route through it

  1. Instrument sets → choose Jahra. Point at the deficit flags and the derived Held column.
  2. Switch to Farwaniya. The Pending chips show what is already asked for and not yet confirmed.
  3. Use − and + on any row, then submit. Note that Held does not move.
  4. Requests → open the Farwaniya request and confirm part of it.
  5. Back to the instrument set — Held has changed. Then Item log for the audit trail.
